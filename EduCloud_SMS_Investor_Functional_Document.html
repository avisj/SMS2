01. Core Architectural Moats & Tech Stack

Key technological advantages that make EduCloud secure, highly scalable, and defensible.

🛡️

Strict Multi-Tenant Isolation

Multi-layered defense with PostgreSQL Row-Level Security (RLS) and Gateway Middleware. Cross-tenant tampering triggers automatic 403 TENANT_VIOLATION rejections and immediate audit logging. No school can ever leak data to another.

👥

Universal User & Dynamic RBAC

Single polymorphic user registry for students, teachers, parents, accountants, and directors. Authorization is decoupled into dynamic roles, rights, and granular data scopes (ALL_SCHOOLS, ONE_LOCATION, ASSIGNED_CLASSES).

🗂️

Multitasking Tabbed Workspace

Inspired by professional financial trading terminals, users can keep up to 8 active modules open concurrently. Form drafts, filter states, table scroll offsets, and active searches persist completely without DOM reload or network thrashing.

Dynamic Role-Rights Matrix & Immutable Audit Trail

Enterprise Security
Role-Rights Permission Matrix

Zero hardcoded permissions in code. Security administrators can map individual rights (students.view, fees.collect, exams.publish) to custom roles and restrict them by Data Scope (ONE_LOCATION, ASSIGNED_CLASSES).

Immutable Security Audit Trail

Every critical mutation (user updates, fee discounts, grade changes, login attempts, unauthorized cross-tenant probes) is written to an append-only audit ledger recording IP address, timestamp, tenant ID, and state changes.
